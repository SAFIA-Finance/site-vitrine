# Pages légales : où déposer les documents

Dépose ici un fichier par page. Le format importe peu : Word (.docx), PDF,
Markdown (.md) ou texte (.txt). Garde des noms explicites :

| Fichier attendu | Page créée sur le site |
|---|---|
| `mentions-legales.*` | /mentions-legales/ |
| `politique-de-confidentialite.*` | /politique-de-confidentialite/ |
| `cgu.*` | /cgu/ |
| `disclaimer.*` | /disclaimer/ |
| `politique-cookies.*` | /cookies/ |

Ce que les textes doivent couvrir, compte tenu de ce qui est en ligne :

- **Politique de confidentialité** : Brevo (inscriptions à la newsletter,
  demandes de démo), Cloudflare (relais technique des formulaires, sans
  conservation), Google Analytics (mesure d'audience après consentement),
  GitHub (hébergement du site).
- **Politique cookies** : Google Analytics, sa finalité, la durée de conservation
  du choix (13 mois) et le lien « Gestion des cookies » du pied de page, qui
  rouvre le bandeau.
- **Mentions légales** : l'hébergeur du site est GitHub, Inc.
  (88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis).

Ces fichiers restent des sources : une fois intégrés, c'est le site qui fait foi.
